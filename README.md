# 🧩 思想拼圖 · Idea Puzzle

把零散的想法片段，透過 AI 分群與整合，拼成完整、可執行的成果（行動計畫、提案、文章、研究報告或路線圖）。

## 快速開始

本專案為純靜態網頁（無框架、無建置步驟）。啟動本機伺服器：

```bash
python3 -m http.server 8123
# 或
npx serve .
```

開啟瀏覽器到 `http://localhost:8123`。

> 建議透過本機伺服器開啟（`file://` 直接開檔會缺少部分瀏覽器 API）。

## 使用流程

1. **收件匣**：輸入文字片段（可貼網址）、錄音、上傳圖片或 PDF。
2. **拼圖工作台**：勾選要整合的片段 → 選擇成果型態 → 「開始分群」→ 確認 AI 分群結果（可手動調整）→ 「確認並整合」。
3. **成果**：檢視整合成果（可追溯引用來源）、匯出 Markdown / 文字 / PDF。

## AI 設定

- 到「設定」貼上免費的 **Google Gemini API 金鑰**（[申請](https://aistudio.google.com/app/apikey)），即可使用真實 AI 分群與整合（免費額度約 1,500 次/日）。
- 語音轉文字可加填 **Groq API 金鑰**（Whisper）或直接用 Gemini 轉錄。
- 未設定金鑰時會以「模擬模式」執行，仍可體驗完整流程。

> ⚠️ 金鑰只儲存在你的瀏覽器 localStorage，不會被上傳到任何伺服器；但瀏覽器直呼 API 時金鑰可被開發者工具看到，請僅個人使用。

## 資料與備份

- 片段預設存於瀏覽器 **IndexedDB**（可離線）。
- 設定頁可「連線資料夾」，將片段同步為 Markdown 檔案（需 Chrome/Edge）。
- 可隨時「匯出/匯入 JSON 備份」。

## 檔案結構

```
index.html         應用骨架（五個畫面）
css/style.css      設計系統（深/淺主題、響應式）
js/app.js          主應用程式（狀態、畫面、拼圖流程）
js/ai.js           AI 層（Gemini 分群/整合、Groq 轉錄、模擬模式）
js/store.js        資料層（IndexedDB、備份、資料夾同步）
```
